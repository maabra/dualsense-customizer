# Generated part icons

`dualsense-parts-atlas-v1.png` is a single transparent 5×5 icon atlas generated with the built-in image generation tool for DualSense Studio. Cells are displayed through CSS without altering the generated artwork. Row-major order follows `advancedParts` in `src/catalog.js`.

The icons illustrate selectable parts; the actual controller preview uses the supplied 3D models. They are not official Sony UI assets.

## Generation prompt

Use case: ui-mockup. Asset type: ONE transparent UI icon atlas sprite sheet for a DualSense controller configurator. Create a perfectly regular 5 by 5 grid on a square 2048x2048 canvas, exactly 25 cells of equal size, one isolated icon centered in each cell, transparent background everywhere around icons. No text, no labels, no gridlines, no panels, no shadows outside the icon. Consistent elegant product-render style: tiny detailed matte white and dark graphite DualSense parts seen straight on from the front, subtle cool blue rim light, readable silhouette, restrained realistic shading. Each icon occupies at most 68% of its own cell width and height, generous identical padding. The parts must be recognizable actual PS5 DualSense-shaped parts rather than abstract symbols. Exact row-major order: Row 1: left front shell wing; right front shell wing; rounded trapezoid touchpad; left rear shell wing; right rear shell wing. Row 2: left center black trim half; right center black trim half; transparent round Triangle face button with triangle engraved; transparent round Circle face button with circle engraved; transparent round Cross face button with X engraved. Row 3: transparent round Square face button with square engraved; D-pad UP directional button pointing up; D-pad RIGHT directional button pointing right; D-pad DOWN directional button pointing down; D-pad LEFT directional button pointing left. Row 4: left concave graphite thumbstick; right concave graphite thumbstick; left L1 shoulder bumper; right R1 shoulder bumper; left L2 curved trigger. Row 5: right R2 curved trigger; slim white Create button with three tiny vertical marks; slim white Options button with three tiny horizontal lines; small black PlayStation home button; small white horizontal mute pill button. Preserve a strictly aligned 5x5 grid so CSS can display each cell independently. Transparent alpha background, no black background, no checkerboard baked in, no words or numbers anywhere.
